# FunBeat

**A hardware-integrated desktop companion for media control and audio visualization.**

FunBeat is an ongoing personal project that combines a Python desktop application with custom hardware to make desktop media interaction more intuitive. It brings together an audio visualizer, a physical tabletop media deck, and an under-desk playback control system.

> **Status:** Under Development

## Overview

FunBeat is built around three main components:

### Audio Visualizer
An audio-reactive visualizer designed to bring music to life through real-time visual feedback.

### Tabletop Media Deck
A custom-built physical control panel featuring a display, switches, and other hardware controls. It is designed to provide quick access to media functions and desktop interactions without relying entirely on a keyboard or mouse.

### Playback Controller
An under-desk control system using physical sensor switches and a microcontroller (MCU) to control media playback through simple, accessible interactions. The goal is to make everyday playback controls feel seamless and unobtrusive.

## Technology Stack

- **Python** — Desktop application and control logic
- **CustomTkinter** — Desktop GUI
- **ESP32 / Arduino** — Microcontroller-based hardware
- **Serial Communication** — Communication between the application and connected devices
- **PlatformIO** — Embedded development

## Development Goals

- Integrate the desktop application with custom hardware.
- Develop responsive, reliable media controls.
- Build a dedicated tabletop interface with a display and physical switches.
- Implement under-desk sensor-based playback controls.
- Improve device communication, connection handling, and overall reliability.

## Current Status

FunBeat is actively under development. Its software, hardware interfaces, and overall architecture are evolving as individual components are built and integrated.

## Project Vision

The goal is to create a workspace where media controls and useful desktop interactions are built into the desk itself—combining software, electronics, and physical interfaces into one cohesive system.
